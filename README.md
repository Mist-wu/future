# future：预测工作区

这是一个用 Claude Code 做概率预测并记录成绩的工作区。它没有后台程序。需要时在这个文件夹里打开 Claude Code 对话，Claude 按操作手册做研究、给概率、记账、结算和算分。

它想回答三个问题：AI 的预测准不准，人和 AI 谁更准，两者合起来是否更准。

## 预测什么

- **事件题**：某件事在某个日期前会不会发生。题目来自 Polymarket，也可以自己提。
- **市场**：BTC、ETH 和 SOXL 在 7 天和 30 天后的价格分布。
- **宏观趋势**：还没做。计划把每个趋势拆成若干道可结算的事件题。

## 成绩怎么保证可信

- **只做前瞻测试**。成绩从 2026-11-11 开始累积，没有回测。语言模型的训练数据里有过去事件的结果，回测分数没有参考价值。
- **账本只追加**。每次运行后提交并推送，提交时间早于结果公布的时间。
- **盲测**。每道事件题记六个数：AI 不看市场价的概率、AI 看过市场价的概率、市场价、人不看 AI 的概率、人看过 AI 后的最终概率、人和 AI 的机械平均。人先给数，之后才看到 AI 的结果和市场价。市场价在 AI 给出盲测值的同一时刻存进账本，之后才揭晓，所以两者可以公平比较。
- **有对照**。事件题和 Polymarket 的市场价比。市场预测和两个基线比：一个是只用历史数据的统计模型，一个是“价格不变加历史平均波动”。

样本少于 30 时，成绩单会标注“仅供参考”。

## 怎么用

需要 Python 3.12 或更高版本，没有第三方依赖。

在这个文件夹里打开 Claude Code，直接说要做什么，比如“跑一次”“预测一下 BTC 走势”“看成绩”。Claude 会按对应的手册执行。

脚本也可以单独运行：

```bash
python3 scripts/market.py forecast BTCUSDT ETHUSDT   # 出统计预测
python3 scripts/market.py settle                     # 结算到期的市场预测
python3 scripts/polymarket.py candidates             # 列候选题，不显示价格
python3 scripts/ledger.py open                       # 未结算的事件题
python3 scripts/score.py                             # 成绩单
```

每个脚本开头的注释里有完整用法。行情来自 Binance 和 Yahoo 的公开接口，题目来自 Polymarket 的公开接口。脚本只读数据，没有下单功能。

## 市场预测的模型

统计预测分三步：

1. 日对数收益率先过一个固定参数的 GARCH(1,1) 滤波，得到标准化残差。
2. 从残差里重新抽样，按当前波动率模拟 20,000 条未来路径。
3. 把模拟结果整体平移，让期望价格等于现价。模型因此不带方向观点。
4. 取期末对数收益率的 199 档分位数，存进账本。

Claude 读新闻后只做两种调整：中枢平移和离散程度缩放。统计原值和调整值都记账，各自用分位数损失打分。

模型改过一次，账本里每条记录的 `model` 字段写着版本，没有这个字段的是 v1。两个版本的成绩分开算。

| 版本 | 使用时间 | 做法 |
|---|---|---|
| v1 | 2026-11-11 和 11-13 的两轮 | 对数收益率的中枢为零。波动大时期望价格会高于现价，SOXL 的 30 天预测偏高约 20% |
| v2 | 2026-11-13 之后 | 期望价格等于现价。中位数因此低于现价，波动越大低得越多 |

## 不在这个仓库里的内容

涉及私事的题目和每道题关系到的个人决定，只存在本机的 `private/` 目录里。公开题的编号以 `q` 开头，私有题以 `p` 开头。这个仓库里的账本和成绩只覆盖公开题。
