# 看成绩

```bash
python3 scripts/score.py            # 全部
python3 scripts/score.py events     # 只看事件题
python3 scripts/score.py market     # 只看市场预测
```

把输出原样贴给用户，再用几句话解读。

## 事件题怎么读

- **Brier 分数**：概率和结果之差的平方，越低越好。永远答 50% 得 0.25，全对得 0。
- **首次 Brier**：只算每道题的第一个概率。六个数是同一时间记下的，互相比较时看这一列。
- **时间加权 Brier**：每个概率按持有的时长加权，反映更新得及不及时。
- **两两比较**：只算双方都有预测的题。重点看四组：AI 盲测对市场价、你的盲测对 AI 盲测、你的最终值对你的盲测值、你的最终值对机械平均。
- **校准表**：说 70% 的题，应该大约有 70% 发生。“预测”明显高于“实际”，说明这个概率段过于自信。

## 市场预测怎么读

- **分位数损失**：整个分布和实际结果的差距，越低越好。只在同一资产、同一周期内比较。
- **区间命中**：90% 区间应该命中九成左右。明显偏低说明分布太窄，偏高说明太宽。
- **AI 调整对统计预测**：差值为负，说明读新闻的调整有用。
- **统计预测对朴素基线**：差值为负，说明模型比“价格不变加平均波动”强。

## 样本量

脚本在样本不足 30 时会标注“仅供参考”。解读时照实说：

- 不到 30 个已结算样本，任何差距都可能是运气。
- 起始时间相近的市场预测，结算窗口大量重叠，不能当独立样本。比如连续 7 天每天出一条 7 天预测，有效样本接近 1 到 2 个。
- 成绩从 2026-11-11 开始累积，没有回测。
