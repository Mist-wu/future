# 市场预测

命令都在工作区根目录运行。资产、周期和阈值在 `config.toml` 的 `[market]` 里。

## 1. 出统计预测

```bash
python3 scripts/market.py forecast BTCUSDT ETHUSDT SOXLUSDT
```

每个资产、每个周期会记两条：

- **统计预测**：从历史日收益率重新抽样，按当前波动率模拟。漂移取零。
- **朴素基线**：价格不变，波动取历史平均。

输出里有五档分位数价格和阈值概率，还有每条预测的编号。阈值按期末价格算，中途触及不算。

## 2. 读新闻

搜这几类信息，记下来源：

- 周期内已排定的事件：美联储议息、CPI 和非农数据、大额解锁、ETF 审批、财报（SOXL 看半导体龙头）。
- 近几天大幅波动的原因，以及原因是否还在。
- 资金面：ETF 净流入流出、合约资金费率、清算规模。

## 3. 调整

调整只有两个旋钮：

- `--drift`：分布的中枢整体平移，单位是百分比。
- `--vol`：离散程度的倍数。1.2 表示区间比统计预测宽 20%。

```bash
python3 scripts/market.py adjust <编号> --drift -1 --vol 1.15 --note "理由，要具体"
```

每条预测都要记一条调整，这样才能和统计预测逐条比较。没有具体理由，就记 `--drift 0 --vol 1`，理由写“无调整”。

怎么定这两个数：

- 方向很难预测。`--drift` 默认是 0，有具体、尚未被价格消化的理由才动。7 天周期一般不超过 ±3%。
- 波动比方向好预测。周期内有重大的排定事件，或者市场刚经历大波动、原因还没消退，`--vol` 可以调到 1.1 至 1.3。行情平静且日历空白时，可以调到 0.85 至 0.95。
- 新闻里人人都在说的事，价格多半已经反映了。

用户说“认真做”时，派 3 个子代理各自读新闻并给出 `drift` 和 `vol`，取中位数，记账时加 `--mode ensemble`。

## 4. 告诉用户

用一张表列出每个资产、每个周期的五档价格，分统计预测和你的调整两行。再用几句话说明：

- 你调了什么，为什么。
- 哪些阈值概率值得注意。
- 这只是概率分布。50% 那一档是中位数，不是目标价。

## 5. 建议下次检查的时间

取下面几个时间里最早的一个作为建议：

- 最近一条预测的结算时间。到期才能结算打分，同时出新一轮预测。
- 周期内最重要的排定事件结束后的第二天。
- 上次检查之后满 7 天。每周一次，样本积累得比较均匀。

再给出提前检查的条件：价格走出 7 天预测的 5% 到 95% 区间，或者出现第 2 步里没预料到的重大消息。

## 查看和结算

```bash
python3 scripts/market.py open      # 未到期的预测
python3 scripts/market.py settle    # 到期的按目标时刻的价格结算
```

结算价是目标时刻那一分钟的开盘价。BTC 和 ETH 用 Binance 现货，SOXL 用 Binance 的 `SOXLUSDT` 永续合约。隔了很久才结算也没关系，脚本会回取历史价格。
